# Todo App

A full-stack Todo management application built with Next.js, Drizzle ORM, and a relational database.

![image_2026-02-16-23-20-26](todo-app.png)

This project supports:

- SQLite for local development
- MySQL for production environments
- Type-safe database access with Drizzle ORM
- REST API using Next.js Route Handlers
- Modern UI built with Tailwind CSS

---

## Tech Stack

- Next.js (App Router)
- TypeScript
- Drizzle ORM
- SQLite (local development)
- MySQL (production)
- Tailwind CSS

---

## Features

- List all todos
- View todo details
- Create new todos
- Update existing todos
- Delete todos
- Filter by status (all / active / completed)
